# SD-WAN

Configuration templates for Cisco SD-WAN (Catalyst SD-WAN).

Use this folder for device configuration templates: cEdge (IOS-XE SD-WAN) CLI and add-on templates, vEdge templates, and shared feature snippets such as system, VPN 0 / VPN 512, transport, and localized policy. Keep organization-specific values as placeholders. Do not store vBond, vManage, or Manager bootstrap credentials, enterprise certificates, or IPsec keys in this tree.

Templates here are for the SD-WAN overlay. The IOS-XE base template in `../IOS-XE/` is for autonomous (non-SD-WAN) IOS-XE and is not a cEdge template.
