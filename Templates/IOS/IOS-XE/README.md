# IOS-XE Configuration Templates

This folder contains configuration templates for Cisco IOS-XE platforms, including
Catalyst 9000 series switches, ASR 1000 series routers, Catalyst 8000v, and CSR 1000v.

Templates here are intended as starting points for demos, labs, and customer-facing
deliverables within the Cisco CX US Public Sector practice. All templates use
placeholder values and do not reflect real customer configurations.

## Platforms Covered
- Catalyst 9200 / 9300 / 9400 / 9500 / 9600
- ASR 1001-X / 1002-X / 1004 / 1006
- Catalyst 8000v / CSR 1000v

## Usage
Replace all placeholder values (e.g., `[HOSTNAME]`, `[IP ADDRESS]`) before
applying any template to a device. Always validate in a lab environment first.
