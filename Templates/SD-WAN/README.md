# SD-WAN Configuration Templates

This folder contains configuration templates for Cisco SD-WAN (Catalyst SD-WAN),
including vManage policies, device templates, feature templates, and CLI add-on
templates for vEdge and Catalyst 8000v/ISR deployments.

Templates here are intended as starting points for demos, labs, and customer-facing
deliverables within the Cisco CX US Public Sector practice. All templates use
placeholder values and do not reflect real customer configurations.

## Platforms Covered
- Catalyst 8000v (cloud and on-prem)
- ISR 1000 / ISR 4000 series with SD-WAN images
- vManage / vSmart / vBond controllers

## Usage
Replace all placeholder values (e.g., `[SITE ID]`, `[SYSTEM IP]`, `[ORG NAME]`)
before applying any template. Templates targeting vManage should be imported and
validated in a lab fabric before pushing to production devices.
